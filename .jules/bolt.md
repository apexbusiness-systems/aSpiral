## 2024-05-21 - [Internationalization & Regex Patterns]
**Learning:** [Using `\w` regex tokens (like `\b\w+\b`) for word matching only matches ASCII characters (`[a-zA-Z0-9_]`), which breaks functionality for non-English languages and accented characters. Performance micro-optimizations that use regex parsing instead of string splitting can introduce severe multi-lingual bugs.]
**Action:** [Avoid using `\w` for word tokenization unless the input is strictly guaranteed to be English/ASCII. Prefer whitespace-based splitting (e.g., `\s+`) or specialized tokenizers when processing potentially internationalized strings, even if it has a minor performance cost.]
