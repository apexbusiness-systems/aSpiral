## 2025-10-25 - Prevent 60FPS React Rendering of 3D Canvas Elements
**Learning:** In a `@react-three/fiber` environment performing 60FPS physics updates via worker calculations, mutating array position props (like `[x, y, z]`) per frame on generic components without strict memoization will trigger massive recursive React re-renders throughout the scene graph, severely crippling CPU budget. Components receiving dynamic callbacks from `useEntities` will also continually break memoization.
**Action:** When working on rapidly-updating R3F scenes, explicitly wrap leaf nodes (e.g., `AdaptiveEntity`, `ConnectionLine`) in `React.memo` with custom element-wise array comparators (e.g., `prev[0] === next[0]`), and guarantee that any dynamic callbacks passed as props (like `onMeshRef`) are cached/memoized by the parent provider to preserve referential equality.
